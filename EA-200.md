# EA-200 — Official SAC nomenclature enrichment

This upgrade adds an optional official tariff nomenclature layer.

## What it changes

- Adds `tariff_catalog`.
- Parses Banguat's official SAC PDF locally.
- Enriches `/analytics/top-items` with `description`.
- Enriches `/analytics/chapters` with chapter descriptions.
- Enriches `/analytics/items/{code}`.
- Shows product descriptions in the React table.
- Shows chapter names next to chapter codes.
- Uses consistent USD compact units (`USD 15.59B`, `USD 800.0M`).
- Keeps all analytics working if the catalog has not been loaded yet.

## Required local source

Save the official Banguat nomenclature PDF as:

`data/raw/sac.pdf`

Then run:

```powershell
.\scripts\load_catalog.ps1
```

The PDF itself is intentionally not included in this patch.
