# EA-300 — Forecasting

Adds a transparent annual export forecasting pipeline.

## Models evaluated

- Naive last-value baseline
- Linear trend
- Holt damped trend

## Model selection

The final model is NOT hardcoded.

The service performs rolling one-step-ahead backtesting over the most recent
five observations and selects the candidate with the lowest MAE (RMSE breaks
ties).

## Forecast horizon

The API accepts 1–5 future years:

`GET /forecast?horizon=3`

The dashboard displays 2026–2028 by default.

## Uncertainty

The displayed range is an approximation based on rolling-backtest residual
dispersion. The API explicitly labels the interval method rather than claiming
it is an exact model confidence interval.

## Important data note

The latest source year, 2025, is provisional and is currently included in the
training series. The dashboard discloses this.

## Apply

Extract this upgrade over the current project, then run:

```powershell
.\scripts\enable_forecasting.ps1
```
